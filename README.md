# 🎵 Spotify Clone – Web Player UI

A Spotify-inspired music player interface built using **HTML and CSS**. This project recreates the look and feel of Spotify's web player with a sidebar, music cards, navigation bar, and a fixed music player.

## ✨ Features

- 🏠 **Sidebar Navigation** – Home, Search, and Your Library sections.
- 🎧 **Playlist Section** – UI for creating playlists and discovering podcasts.
- 🧭 **Sticky Navigation Bar** – Navigation icons, Explore Premium, Install App, and user profile.
- 🎵 **Recently Played** – Displays music cards with album artwork and descriptions.
- 🔥 **Trending Music** – Horizontally scrollable music cards.
- 📊 **Featured Charts** – Displays popular music charts.
- 🎼 **Music Player UI** – Album artwork, song title, artist name, and playback controls.
- 🔊 **Volume Control** – Styled volume slider.
- 🎨 **Dark Theme** – Spotify-inspired dark interface.
- 📱 **Responsive Adjustments** – CSS media queries for smaller screens.

## 🛠️ Technologies Used

- **HTML5** – Page structure and content.
- **CSS3** – Styling, layouts, hover effects, and scrolling.
- **Font Awesome** – Icons for navigation and controls.
- **Google Fonts** – Montserrat typography.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone (https://github.com/GauravGuptaCoder1/Spotify-clone.git)
```

### 2. Navigate to the Project Folder

```bash
cd spotify-clone
```

### 3. Run the Project

Open `index.html` in your web browser.

Alternatively, use the **Live Server** extension in Visual Studio Code to run the project locally.

## 🎨 Design Highlights

- Dark background inspired by Spotify's interface.
- Flexbox-based layouts for the sidebar, navigation bar, and music player.
- Horizontally scrollable music card sections.
- Hover effects for icons, links, and playback controls.
- Fixed bottom music player.
- CSS line clamping for music descriptions.
- Custom-styled playback and volume sliders.
- Montserrat font for consistent typography.
